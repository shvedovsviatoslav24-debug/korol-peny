# Король пены / King of Foam

3-минутная браузерная аркада о жадности по мотивам песни «В синем море, в белой пене».

**Играть: https://shvedovsviatoslav24-debug.github.io/korol-peny/**

Держи кнопку — волна растёт. Отпусти выше борта — корабль твой. Русалки замедляют корабли, но каждые 20 секунд забирают долю золота. Спасай людей с обломков — они страхуют твоё золото. Уйди на берег до полуночи.

A 3-minute greed arcade. Hold to raise the wave, sink ships, pay the mermaids their growing cut, escape before midnight. One HTML file, no dependencies, no sign-up.
